# Nova installation

Use the verified [GitHub Release archives](https://github.com/bigduu/Nova/releases)
for the published desktop tools, or build the source for newer workflows.
This directory is not an npm installation recommendation: use the
[version and installation guide](../README.md#choose-a-version) to match the
README capabilities to the binary you install.

Nova's optional `chrome-devtools` command launches an official Node package;
it is separate from installing the Nova desktop binary.
